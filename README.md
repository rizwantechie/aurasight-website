# AuraSight Eye & Wellness Centre – Website

A clean, modern, fully responsive single-page website for **AuraSight Eye & Wellness Centre**, Ludhiana.

## Features

- Professional hero section matching the clinic branding
- Eye Care Services + Women’s Health & Wellness sections
- Why Choose Us section
- Contact details + Google Maps-ready address
- Call & WhatsApp buttons (pre-filled message)
- Appointment request form that opens WhatsApp with the user’s details
- Fully responsive (mobile + tablet + desktop)
- Smooth scrolling & mobile menu

## How to use

1. Open `index.html` in any browser to preview.
2. Upload the entire folder to any hosting (Netlify, Vercel, GitHub Pages, Hostinger, etc.).
3. No build step required – it’s pure HTML, CSS & a little JavaScript.

## Customisation tips

- **Logo**: Replace the emoji icon with your actual logo image.
- **Images**: Add real clinic photos in the hero and service sections.
- **Working hours**: Update the timings in the contact section.
- **Form**: Currently sends data via WhatsApp. You can later connect it to Google Forms, Formspree, or a backend.
- **Colours**: All main colours are defined as CSS variables at the top of the `<style>` section – easy to change.
- **Google Maps**: You can embed a map iframe in the contact section if needed.
